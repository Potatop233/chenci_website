# 晨辞の小站

基于 Vue 3 + TypeScript + Vite 构建的个人主页。
视频背景、打字机动画与流畅的动效。

## Demo

🔗 [https://me.ycly.net](https://me.ycly.net)

## 技术栈

| 分类 | 技术 |
|------|------|
| 框架 | Vue 3 |
| 语言 | TypeScript |
| 构建 | Vite |
| 路由 | Vue Router 4 |
| 样式 | Tailwind CSS v4 + daisyUI |
| 动画 | Motion-v |
| 打字效果 | TypeIt.js |
| 图标 | @xicons |

## 本地运行

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 预览构建结果
pnpm preview
```
